01 / Gather your kit

What you'll need.

You can assemble the project with a screw-terminal breakout board and a few wires. A 3D-printed housing is available from the original maker.

01 — CONTROLLER

30-pin ESP32

ESP-WROOM-32 development board, with USB connection for flashing and power.

02 — SCREENS

Two round TFTs

1.28-inch GC9A01, 240×240, SPI, 7-pin. One for the radar; one for the clock.

03 — WIRING

Breakout + wires

Optional 30-pin screw-terminal breakout for solder-free assembly, plus hookup wires.

04 — FINISHING

USB data cable

A real USB data cable for installing firmware; suitable USB power for everyday use.

02 / Connect the displays

Simple, shared wiring.

Both displays share the same clock and data pins. Each display has its own CS, DC and reset pins. These are the original SkyOrb GPIO assignments; no rewiring is required for an existing build.

SkyOrb Community Edition · USB installer

Install SkyOrb firmware

Use a Windows, macOS, or Linux computer with Google Chrome or Microsoft Edge. Plug in your ESP32 using a USB data cable, then select its serial port when prompted.

This browser doesn't support USB installation. Please open this page in desktop Chrome or Edge. USB access is unavailable here. Use this page over HTTPS in Chrome or Edge on your computer.

04 / Configure your radar

Then use your phone.

Setup happens over Wi-Fi, not over the USB installer. Your ESP32 connects to a 2.4 GHz home network and then serves its own local settings dashboard.

STEP 01 — CONNECT

Join the setup hotspot

On your phone, join Wi-Fi SKYORB-Setup using password SKYORB1234.

STEP 02 — SAVE WIFI

Select your home network

If the captive portal doesn't pop up, browse to http://192.168.4.1/setup. Pick your 2.4 GHz Wi-Fi network and save its password.

STEP 03 — CUSTOMIZE

Open your dashboard

Reconnect your phone to your normal home Wi-Fi, then open the numeric IP address shown on SkyOrb. Choose your address, radar radius, airports, colors, and 12/24-hour clock.

Can't open the dashboard? http://skyorb.local/ sometimes works, but the on-screen IP address is more reliable. Your phone/computer and SkyOrb must be on the same local network. For example, a device on 10.0.0.x might not reach one on 192.168.86.x. If the setup hotspot disappears, restart SkyOrb and reconnect.

05 / Quick troubleshooting

Common questions.

A few practical things we learned from testing this community remake.

My computer doesn't see the ESP32.

Confirm that you are using a USB data cable, not a charge-only cable. Try a direct USB port, close software using the COM port, and retry in desktop Chrome or Edge. Some ESP32 boards require a USB-to-serial driver.

The installer fails while writing firmware.

Don't keep repeating failed flashes. Try the known-good cable and a stable USB port. If it fails at the same point again, check the GitHub repository for guidance before erasing anything.

Why can't I reach the settings page?

Switch your phone back to your normal home Wi-Fi after saving credentials. Use the IP address shown on SkyOrb; computers on a different router/subnet may not be able to reach it. skyorb.local relies on mDNS and may be unavailable.

There aren't any airplanes or airports.

First save a real radar location and try the 20- or 30-mile range. Aircraft depend on external ADS-B feeds and coverage. This edition generates an offline airport catalogue during the firmware build, so airport discovery does not depend on the earlier live Overpass lookup.

Is the radar animation identical to the original?

Not exactly. This is independently rebuilt firmware using different display-drawing code. Sweep smoothness can vary, and minor trails may still be visible on some hardware.

Can I use the original enclosure or wiring?

Yes, this remake deliberately keeps the original dual-display GPIO wiring. See the original SkyOrb MakerWorld page for the creator's housing and printed-part instructions.
